# 浏览、导出与离线分离操作说明

本文说明当前使用方式；精确的数据、单位和结果格式见 [契约](contracts.md)，尚未完成的效果与平台验收见 [清单](feature-parity-checklist.md)。下载安装包见 [发布 SOP](release-sop.md)，不要从历史报告选旧包。

## 波形浏览与片段导出

打开记录后，波形和频谱分析共用“原始/处理后”数据来源。原始模式跳过参考与滤波，保留处理设置；处理后模式应用重参考、陷波、全局及逐通道带通。切换参考可能改变输出通道数与名称；原始模式禁用逐通道处理编辑。

片段导出在一个弹窗中设置开始、结束和数据来源，默认使用当前可见区间和模式。可以独立改选原始或处理后，无需改变浏览模式。输出 EDF/HDF5/CSV，并携带区间内标注，标注时间重基准到导出片段起点。处理后导出捕获打开弹窗时的参数；缓存内片段先处理缓存上下文再裁剪，缓存外片段使用所选区间作为滤波上下文，因此边界可能不同。

显示幅度、显隐和绘图抽稀不改变科研样本。处理后导出仍受单帧 `256 MiB` 限制，不是任意长度的整文件流式滤波导出；EDF 还受其量化与记录填充规则约束。

## 进入脑电 / 眼电分离

主窗口顶部“波形浏览”“脑电 / 眼电分离”与视图菜单同步。进入分离暂停浏览播放，返回浏览暂停分离预览；普通切换保留输入、结果、标签和确认。浏览换文件会清理旧分析；这不是跨重启项目存储。

第一次体验可点击“打开教学记录 → 开始分离”。教学文件来自自有数学混合信号，软件验证文件哈希、采样信息和通道映射后才预填用途。它用于学习操作，不是 EEGdenoiseNet，也不代表真实眼周采集效果；完整 EEGdenoiseNet 半合成基准仍待独立完成。

真实记录按以下顺序操作：

1. 打开用于分析的记录，检查单位、采样信息和硬件带宽/参考。未知值显示未知；采集时滤掉的频率不能靠分离恢复。
2. 将至少两路独立混合信号设为观测通道；按实际采集配置设置可选眼电/肌电参考、排除坏通道。可多行选择后批量应用。仅作参考的通道用于评分，不参与拟合。
3. 设置源记录中的起始和时长，再开始分离。默认输出 `500 Hz`、陷波关闭；源速率不足 `500 Hz` 时默认 `250 Hz`，低于 `250 Hz` 当前不支持。分析区间 `5–120 s`，观测 `2–32` 路，观测加参考最多 `40` 路。
4. 检查右侧独立成分的波形、频谱、通道载荷与参考线索，再人工标记脑电候选、眼电、肌电或未确定。初始全部为“未确定”，此时其他组显示零线是预期行为。参考相关与高频能量不是准确率或来源证明。
5. 标签修改即时更新五组贡献，不重新拟合；支持撤销与 `Ctrl+Z`。允许保留未确定成分，检查并确认后导出到新的结果目录。

修改分析输入使旧结果与确认失效；只改变查看通道、视窗、主题或预览放大不重新拟合。分离输入不继承浏览中的重参考、滤波或绘图抽稀。

## 预览与播放

独立成分采用任意单位，投影到观测通道的分组贡献采用 `µV`。默认统一标尺方便比较幅度；“各组适配”方便观察小波形，但各行显示高度不能用于跨组幅度比较。放大倍数只改变显示，峰峰值按当前通道和可见窗口计算，与显示增益无关。

结果支持播放/暂停、回到开头与拖动定位，固定 1 倍速度；中间五组与所选成分同步。到末尾停止并保留最后一屏，再播放从头开始。源时间坐标与分析区间内播放位置分别显示；纵轴按整段结果固定，功率谱也使用整段分析，不随播放重新拟合。

输入、标签、查看通道、视窗、幅度或成分切换，以及隐藏页面和导出会暂停播放；相应显示操作不修改科学数组。

## 专用分离输入条件

通用浏览和专用分离读取能力不同，不能把一个入口支持的格式推定到另一个入口。

| 输入 | 专用分离条件 |
| --- | --- |
| RHD / RHS | 传统单文件附头记录；Neo RawIO memmap 放大器片段，检查时间戳连续/回绕、单位及 ADC 轨值；拒绝 `info.rhd/info.rhs` 多文件布局 |
| HDF5 | 明确 `eeg[C,N]`、正 `fs`、通道名和物理单位；拒绝外链、虚拟数据和未支持的不规则时间轴 |
| EDF / 连续 EDF+ | 同采样率/样本数、明确物理单位与校准；拒绝 EDF+D、BDF 伪装和不支持布局；不宣称验证了不存在的逐样本硬件时间戳 |
| CSV | UTF-8，首列 `time_s`，从 0 开始且有限均匀；列尾声明 `[uV]/[mV]/[V]`，或人工确认单位；不能猜未知单位 |

专用读取在分配前按 double 字节数检查 `256 MiB` 上限；这不是进程峰值内存保证。来源哈希和 CSV 全轴验证需要顺序扫描，未宣称大型文件性能门禁。

浏览端的 Intan Neo 入口与上述专用整数片读路径不同，不能套用其内存、时间轴或单位校验保证。供应商文件的真实样本和事件覆盖仍需单独验收。

## 结果文件与恢复边界

结果是七份 CSV 加 `analysis.json`：

| 文件 | 内容 |
| --- | --- |
| `original_uV.csv` | 抗混叠重采样后、可选陷波前的观测副本，不是源文件原始字节 |
| `analysis_uV.csv` | 实际重建输入 |
| `eeg_uV.csv`、`eog_uV.csv`、`emg_uV.csv` | 人工标签对应的贡献 |
| `unresolved_uV.csv`、`residual_uV.csv` | 未确定贡献和残差 |
| `analysis.json` | 源指纹、样本区间、通道用途、设置、版本、矩阵、均值、收敛、线索、标签、确认及校验值 |

CSV 时间列相对源文件，数值用 17 位可回读精度；专用读取和结果传输使用 float64。导出先检查 `analysis = mean + eeg + eog + emg + unresolved + residual`，写暂存、逐值回读并再次核对来源后，以不覆盖方式发布。失败可保留内存结果和标签，更换目录重试。

正常取消清理暂存；断电或强杀可能留下 `.boundfree-analysis-*` 隐藏目录，它不是正式结果，当前没有跨崩溃自动恢复。人工标签、参考相关或受控合成源回归都不能证明真实电极信号已纯净分离。

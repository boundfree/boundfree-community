# 浏览、导出与离线分离操作说明

本文说明当前使用方式；精确的数据、单位和结果格式见 [契约](contracts.md)，尚未完成的效果与平台验收见 [清单](feature-parity-checklist.md)。下载安装包见 [发布 SOP](release-sop.md)，不要从历史报告选旧包。

## 波形浏览与片段导出

打开记录后，波形和频谱分析共用“原始/处理后”数据来源。原始模式跳过参考与滤波，保留处理设置；处理后模式应用重参考、陷波、全局及逐通道带通。切换参考可能改变输出通道数与名称；原始模式禁用逐通道处理编辑。

打开设备录制时默认显示 2 秒，横轴和频谱分析区间与窗口控件一致；初次读取的 10 秒原始缓存仍用于后续浏览和分离取样，缓存长度不决定可见窗口。宽屏布局默认将更多宽度分配给中间波形，左右工具区保持紧凑，仍可拖动分隔条调整。

片段导出在一个弹窗中设置开始、结束和数据来源，默认使用当前可见区间和模式。可以独立改选原始或处理后，无需改变浏览模式。输出 EDF/HDF5/CSV，并携带区间内标注，标注时间重基准到导出片段起点。处理后导出捕获打开弹窗时的参数；缓存内片段先处理缓存上下文再裁剪，缓存外片段使用所选区间作为滤波上下文，因此边界可能不同。

显示幅度、显隐和绘图抽稀不改变科研样本。处理后导出仍受单帧 `256 MiB` 限制，不是任意长度的整文件流式滤波导出；EDF 还受其量化与记录填充规则约束。

文件和设备使用同一个波形浏览区：Ctrl＋滚轮围绕指针缩放时间，Shift＋滚轮缩放幅值，普通滚轮滚动通道。点击文件波形后，＋/－缩放时间，空格播放/暂停，0或双击恢复10秒窗口与1倍显示倍率（短文件显示至结尾），保留自动/手动幅值模式。文件暂停播放且未开启标注时，可拖动或按左右方向键浏览；超出已加载缓存时通过边车读取。文件时间窗口为0.25–120秒，显示倍率为0.25–16倍。设备的实时跟随、暂停查看和缓存范围独立管理；暂停查看不停止采集或原始录制。来源切换不恢复已经关闭的旧文件会话。

## 进入脑电 / 眼电 / 肌电分离

主窗口顶部保留“波形浏览”和“脑电 / 眼电 / 肌电分离”。设备连接统一从菜单栏“设备 → 连接设备”打开原有管理窗口。进入分离暂停浏览播放，返回浏览暂停分离预览；普通切换保留输入、结果、标签和确认。浏览换文件会清理旧分析；这不是跨重启项目存储。

ICA 使用已连接设备的信号，或从菜单栏“文件”打开原文件、教学记录。分离页不再重复提供文件打开区域。文件菜单按实际对象命名：“打开数据文件…”选择自己的科研数据文件；“打开设备录制文件夹…”选择设备录制生成的整套目录，先进入波形回放；“加载内置分离示例”直接加载随包合成数据并进入分离，用于练习，不是自己的记录或已保存的分析结果。“文件”的打开命令按当前工作区操作：波形浏览时打开浏览文件，分离时同样显示“打开数据文件…”并使用专用读取；Ctrl+O遵循同一规则。“加载内置分离示例”位于文件菜单并进入分离工作区。文件入口仍经边车专用 float64 读取；设备入口复用设备适配后的完整采样窗口，不读取绘图包络，也不继承浏览滤波、重参考或显示缩放。设备连接统一在菜单栏“设备”的连接窗口完成，连接成功后自动显示波形；分离页不再提供连接设备选项。进入分离页时自动读取当前已连接设备的建模片段；需要更换片段时点击“重新获取建模片段”，多数据流时可选择一条流。左侧“当前分析输入”显示实际使用的记录或设备片段；“可取样设备”仅说明可重新取样的后台设备，不表示教学文件已经切换为该设备。设备已连接且正在浏览文件时，也可直接获取设备片段，无需切换主波形来源。

获取设备片段会从当前设备缓存（最多 10 秒/32 MiB）选择最长连续区间，等长时选较新的区间，至少 5 秒；不会跨缺口拼接或补样。首次从波形页切入且尚无 ICA 输入时，设备按同一接口取样，文件使用当前已加载的完整原始窗口（最多取 120 秒连续区间），不再被默认 2 秒的绘图视窗截短。文件窗口不够长时，可扩大加载窗口或直接打开原文件。通道单位必须兼容，采样率和通道数量仍受下述算法条件约束。

片段取到后固定，继续到来的设备数据不替换当前输入或逐帧重算。再次点击“重新获取建模片段”会替换旧结果、人工标记和确认；来源身份、数据流、通道身份/单位及采样率均相同时保留通道用途、输出率和陷波设置。采集、原始录制和浏览参数独立继续。获取失败保留已有输入与结果，可再次点击取样；设备重连、配置代际变化或浏览换源后，过期异步请求不能覆盖新来源。

面板明确显示来源名称、模拟标记、原始区间及实际单位。共享窗口和设备快照是 float32 投影，以临时 HDF5 衔接已有专用读取/计算链路，之后使用 double 计算与 float64 结果导出；该过程不恢复投影前的精度。快照内起始时间从 0 计，原设备/文件区间、通道身份、单位、采集时钟说明及模拟属性保存在 `analysis.json` 的 `source.signal_provenance`。快照导出结果默认保存到用户文档目录，临时快照不是跨重启项目存储。需要原文件 float64 精度时使用“打开数据文件…”入口。

第一次体验可点击“文件 → 加载内置分离示例”，再点击“开始分离”。教学文件来自自有数学混合信号，软件验证文件哈希、采样信息和通道映射后才预填用途。它用于学习操作，不是 EEGdenoiseNet，也不代表真实眼周采集效果；完整 EEGdenoiseNet 半合成基准仍待独立完成。

真实记录按以下顺序操作：

1. 打开用于分析的记录，检查单位、采样信息和硬件带宽/参考。未知值显示未知；采集时滤掉的频率不能靠分离恢复。
2. 将至少两路独立混合信号设为观测通道；按实际采集配置设置可选眼电/肌电参考、排除坏通道。可多行选择后批量应用。仅作参考的通道用于评分，不参与拟合。
3. 设置源记录中的起始和时长，再开始分离。默认输出 `500 Hz`、陷波关闭；源速率不足 `500 Hz` 时默认 `250 Hz`，低于 `250 Hz` 当前不支持。分析区间 `5–120 s`，观测 `2–32` 路，观测加参考最多 `40` 路。
4. 检查右侧独立成分的波形、频谱、通道载荷与参考线索，再人工标记脑电候选、眼电、肌电或未确定。初始全部为“未确定”，此时其他组显示零线是预期行为。参考相关与高频能量不是准确率或来源证明。
5. 标签修改即时更新五组贡献，不重新拟合；支持撤销与 `Ctrl+Z`。允许保留未确定成分，检查并确认后导出到新的结果目录。

结果页的“重新分离”可再次计算当前区间，会替换现有结果、人工标记和确认；“导出结果”在勾选“已检查成分”后可用。取消文件选择不会丢失结果，重复导出会建议尚不存在的新文件夹名称；已有目标不会被覆盖，可换名称重试。导出重试同样要求人工确认；修改或撤销标记后清除旧的导出提示，并要求重新确认。

分离页顶部持续标明四步流程：准备信号 → 建立模型 → 检查成分 → 查看结果，并突出当前步骤。步骤条下方是固定操作区，统一放置“建立分离模型／导出结果”“重新分离”“开始／停止连续 ICA”“取消”和可用的“重试”，小窗口自动换行；取样保留在左侧当前输入，分类和“已检查成分”保留在右侧。当前可执行的主操作使用强调色；检查成分期间先按提示完成人工确认，再启用导出并显示连续 ICA 入口。

错误在同一操作区内以红色文字和浅红背景显示，并标明“错误”；输入条件和连续 ICA 兼容性问题用“注意”及警告色，普通进度和主动取消不作为失败，导出成功使用成功色。明暗主题共用 Fluent 语义色。错误恢复后清除旧提示和 tooltip；只有可重试的任务错误才提供“重试”，导出重试仍需要人工确认，不影响旧结果和已有目标文件。观测通道不足或过多时单独说明 2–32 路要求，不再混用区间错误提示。文件分析继续保留专用读取与结果导出。

## 设备连续 ICA

连续模式先建立一次 ICA 模型，再将固定的解混/混合矩阵和均值应用到同一设备的新原始样本；不会每帧重新拟合、自动认定脑电/眼电/肌电或更改原始录制。当前候选支持设备与建模输出同为 **250 或 500 Hz**、陷波关闭。浏览滤波与重参考不进入此链路；其他采样率或离线陷波模型仍可做片段分析，但不能启动连续显示。

本地练习可在“设备 → 高级连接方式”选择“ICA 混合信号”，再使用模拟设备。进入分离页后，三路混合观测与眼电、肌电参考自动分配用途。完成建模后可应用教学标记、确认成分并开始连续ICA；停止后可导出建模片段。设备录制独立保存连续原始数据，回放后仍可再次分离。

1. 在菜单栏“设备”的连接窗口连接设备，连接成功后自动进入波形浏览；再进入“脑电 / 眼电 / 肌电分离”，自动准备建模片段。无需在分离页重新连接设备。不足 5 秒连续数据时显示当前进度并自动等待，最多 30 秒，可取消。失败或取消保留旧输入与结果，采集和录制继续。
2. 设置通道用途。全部都是有效混合观测时可点击“全部设为观测通道”；坏通道应排除，参考通道单独指定。点击“建立分离模型”。
3. 检查成分波形/频谱并人工标记；勾选“已检查成分”，点击顶部“开始连续 ICA”。中间分组波形和右侧成分波形随设备新数据持续更新，状态显示最新设备相对时间。独立成分仍为任意单位，投影贡献保持输入的实际单位（含 RT-BCI 的 count），不把未知标定当成 µV。
4. 连续显示时可以改成分标签，投影随标签更新，模型不变。逐通道与批量通道用途、建模参数、替换输入和片段导出暂时锁定；即使开始前已多选通道，也不能在连续显示中批量改用途。点击“停止连续显示”返回原建模结果，可重新获取片段、拟合或导出。导出仍只保存建模片段的已有八文件结果，**不保存整段连续分离信号**；需要原始长记录时单独开启设备录制。

切换工作区、暂停主波形查看不停止连续处理或原始录制。停止采集、断开、设备重连或来源/通道顺序/单位/采样率变化后停止应用旧模型，必须重新建模；收到的数据不再前进超过 2.5 秒也结束连续显示，避免把旧波形当成实时更新。缺口保留为断线，不补零、不跨缺口计算频谱；实时频谱使用当前窗口内最长连续片段。连续显示中的参考线索不重新评分，停止后查看建模片段的评分。当前使用最多 10 秒滚动原始窗口、后台单个在途处理任务、约 200 ms 调度；不承诺硬实时截止时间或所有硬件负载性能。

固定模型的分离效果取决于建模片段、通道质量和混合关系是否稳定。电极或采集条件改变后应重新建模；人工分组仅为候选贡献，不是来源确证。连续结果的长记录导出、模型跨会话保存、自动模型更新和实机长期效果尚未验收。

用途下拉项及当前选项提供完整说明。说明统一从页面右上角“使用说明”（F1）打开可与工作区并用的非模态窗口，包含操作步骤、通道用途、波形操作、采集信息与成分检查五页；已有分离结果时默认打开成分检查。左侧用途说明、中间快捷操作及分离页底部操作说明按钮已移除；当前输入区域的“采集信息…”直接打开当前记录的采样率、通道数、时长、单位与已知硬件信息，输入变更时同步更新。原左侧底部“使用说明与采集信息”折叠区已移除。

点击分组波形后，Ctrl＋滚轮围绕指针缩放时间轴，Shift＋滚轮缩放幅值；＋/－缩放时间，↑/↓缩放幅值，←/→或按住左键拖动平移离线查看窗口或已暂停的连续窗口，0或双击恢复10秒窗口/1倍幅值，空格播放/暂停离线结果，或暂停/继续连续查看。时间窗与幅值下拉框同步显示当前值，持续缩放复用一个自定义项；时间窗最小0.2秒、最大当前结果长度，幅值0.25–16倍。平移不改变播放位置，播放/定位后恢复跟随播放位置；连续显示缩放后仍跟随最新信号。操作仅调整显示，保留模型、标签、确认和导出区间。底部设备采集操作栏在波形浏览与分离页共用同一实例；采集、原始录制、日志始终操作同一个设备，暂停查看/重置作用于当前页面，分离页的操作说明统一在右上角。连续 ICA 暂停查看保留一个固定帧，后台投影、采集与录制继续，恢复后返回最新帧；暂停期间改变成分标签会按固定帧的成分重新分组。

IC波形支持Ctrl＋滚轮缩放共享时间窗口、Shift＋滚轮独立缩放当前成分幅值，键盘、拖动与双击重置沿用分组波形操作。时间范围与游标保持同步，IC幅值调整保留中间分组的标尺。两类波形显示时间刻度和幅值刻度；观测贡献采用输入实际单位，IC采用任意单位（a.u.）。频谱显示频率（Hz）与从零开始的功率谱密度（a.u.²/Hz）。

成分检查列表显示IC编号与当前分类。选中一行，或用“上一个/下一个”切换成分；在“IC波形、频谱、参考指标”标签中查看信息，再用四个单选项设置分类。分类项提供悬停说明，支持撤销与示例标记。分类单选项与撤销、应用示例标记操作通过分隔线分区；底部“已检查成分”用于完成确认。右侧预览采用标签布局。

分组波形标题同步显示当前观测通道、分类及贡献IC，例如“脑电候选 · Mixed-1 · IC 2 贡献 · uV”。多个IC归入同组时列出全部编号；长文本省略显示，悬停与可访问描述保留完整内容。分析输入标题单独标明当前通道与均值处理，空组显示“暂无成分”。

勾选“已检查成分”进入第4步并启用导出，支持保留未确定成分；修改分类后需重新确认。内置分离示例与模拟设备的 ICA 混合信号支持教学标记，可用于分类练习。

界面提示与帮助正文采用简短专业表达。操作、分类与确认规则分段展示，详细内容统一在右上角说明。

修改分析输入使旧结果与确认失效；只改变查看通道、视窗、主题或预览放大不重新拟合。分离输入不继承浏览中的重参考、滤波或绘图抽稀。

## 预览与播放

独立成分采用任意单位，投影到观测通道的分组贡献采用输入实际单位（如 `µV`、`count`）。默认统一标尺方便比较幅度；“各组适配”方便观察小波形，但各行显示高度不能用于跨组幅度比较。放大倍数只改变显示，峰峰值按当前通道和可见窗口计算，与显示增益无关。

结果支持播放/暂停、回到开头与拖动定位，固定 1 倍速度；中间五组与所选成分同步。到末尾停止并保留最后一屏，再播放从头开始。源时间坐标与分析区间内播放位置分别显示；纵轴按整段结果固定，功率谱也使用整段分析，不随播放重新拟合。

输入、标签、查看通道、视窗、幅度或成分切换，以及隐藏页面和导出会暂停播放；相应显示操作不修改科学数组。

## 专用分离输入条件

通用浏览和专用分离读取能力不同，不能把一个入口支持的格式推定到另一个入口。

| 输入 | 专用分离条件 |
| --- | --- |
| RHD / RHS | 传统单文件附头记录；Neo RawIO memmap 放大器片段，检查时间戳连续/回绕、单位及 ADC 轨值；拒绝 `info.rhd/info.rhs` 多文件布局 |
| HDF5 | 明确 `eeg[C,N]`、正 `fs`、通道名和物理单位；拒绝外链、虚拟数据和未支持的不规则时间轴 |
| EDF / 连续 EDF+ | 同采样率/样本数、明确物理单位与校准；拒绝 EDF+D、BDF 伪装和不支持布局；不宣称验证了不存在的逐样本硬件时间戳 |
| CSV | UTF-8，首列 `time_s`，从 0 开始且有限均匀；列尾声明 `[uV]/[mV]/[V]`，或人工确认单位；不能猜未知单位 |

专用读取在分配前按 double 字节数检查 `256 MiB` 上限；这不是进程峰值内存保证。来源哈希和 CSV 全轴验证需要顺序扫描，未宣称大型文件性能门禁。

浏览端的 Intan Neo 入口与上述专用整数片读路径不同，不能套用其内存、时间轴或单位校验保证。供应商文件的真实样本和事件覆盖仍需单独验收。

## 结果文件与恢复边界

结果是七份 CSV 加 `analysis.json`：

| 文件 | 内容 |
| --- | --- |
| `original_uV.csv` | 抗混叠重采样后、可选陷波前的观测副本，不是源文件原始字节 |
| `analysis_uV.csv` | 实际重建输入 |
| `eeg_uV.csv`、`eog_uV.csv`、`emg_uV.csv` | 人工标签对应的贡献 |
| `unresolved_uV.csv`、`residual_uV.csv` | 未确定贡献和残差 |
| `analysis.json` | 源指纹、样本区间、通道用途、设置、版本、矩阵、均值、收敛、线索、标签、确认及校验值 |

CSV 时间列相对源文件，数值用 17 位可回读精度；专用读取和结果传输使用 float64。导出先检查 `analysis = mean + eeg + eog + emg + unresolved + residual`，写暂存、逐值回读并再次核对来源后，以不覆盖方式发布。失败可保留内存结果和标签，更换目录重试。

正常取消清理暂存；断电或强杀可能留下 `.boundfree-analysis-*` 隐藏目录，它不是正式结果，当前没有跨崩溃自动恢复。人工标签、参考相关或受控合成源回归都不能证明真实电极信号已纯净分离。

# 脑电眼电离线分离工作区实施与验收

在 `feature/offline-eeg-separation` 实施用户确认的“完整离线流程＋专用工作区”，当前产品版本为 `0.2.2-dev`。入口是“视图 → 脑电 / 眼电分离”。保留脑电候选和眼电估计，肌电贡献、未确定贡献与残差一起可追溯输出。人工标签不代表生理来源已获证明。

## 操作路径与体验

首次体验点击“打开教学记录 → 开始分离”，无需先配置 ICA 参数。随包教学记录来自自有数学信号，不包含外部数据库或患者记录；按文件 SHA-256、采样信息与通道映射验证后才预填三路观测和两路参考。

真实记录逐项确认通道用途，支持多行选择后批量设置；参考可选，不参加混合拟合。默认输出 500 Hz、陷波关闭，高级设置折叠；源速率不足 500 Hz 时默认 250 Hz，低于 250 Hz 则明确不能使用当前版本。输入范围是 5–120 秒，2–32 路观测、观测加参考至多 40 路。

分离后所有成分先进入“未确定”。零线区域说明该组尚无成分；下一步提示引导用户检查右侧波形、频谱和来源线索。数字参考相关默认折叠，不显示为准确率；没有参考时显示未提供参考。分类立即更新五组同轴、同 µV 标尺预览，不重新拟合；支持撤销及 Ctrl+Z。独立成分显示任意单位，投影显示 µV。

修改输入使旧结果与确认失效；改变视窗、观测通道或主题只影响显示。允许保留未确定成分，人工检查确认后即可导出。确认和主操作固定可见，证据区独立滚动，1280×900 下已做真实 Qt 布局与四语＋pseudo 逐项文字回归。

本轮交互改进（`0.2.1-dev`）：默认统一标尺用于幅度比较；“各组适配”便于观察小波形，并持续提醒各组高度不能用于幅度比较。“显示放大”支持 1/2/5/10 倍，所有这些操作只改变预览，保留拟合结果、标签、输入与人工确认。五组逐行显示当前通道、当前时间视窗的物理峰峰值（µV），与显示增益无关；小于 `1e-9 µV` 的数值只在文案中显示为 0，原始数组与导出精度不变。非空组的峰峰值小于显示全量程的 2% 时提示波形较小；放大超出显示范围时裁剪到本行绘图区并提示减小放大倍数。

左右区域间采用 12 px 常驻握柄，可鼠标拖动，也支持聚焦后左右方向键调整；输入列可扩大。通道用途仍支持逐行修改，批量工具仅在选择至少两行时出现，显示数量并明确“应用到这 N 个通道”，减少重复控件和误操作。四语和 pseudo 均覆盖新增文案。

从浏览进入会暂停并保留回放位置；分离输入不继承浏览带通、重参考、逐通道滤波或绘图抽稀。硬件带宽及参考有值时显示，缺失则显示未知；软件无法恢复采集时已滤除的频率。切换浏览记录清理旧分析，普通同文件读片不触发清理。

## 结果播放与工作区导航

`0.2.2-dev` 在主窗口顶部提供始终可见的“波形浏览”和“脑电 / 眼电分离”两个工作区入口，并与视图菜单同步。进入分离暂停浏览播放，离开分离暂停结果预览；普通切换保留当前结果、输入、标签及人工确认，返回后保持暂停。首次从浏览进入空白分离工作区时继承浏览源，分离工作区单独打开的记录不会自动加载到浏览页面。浏览中切换记录仍按既有规则清理旧分析，导航不是持久化项目存储。

查看控件有可见标签“查看通道”“每屏显示”“波形放大”。预览增加播放/暂停、回到开头和相对于分析区间的播放位置；实际推进用单调经过时间，固定 1 倍速度，40 ms 的 UI 定时器只触发刷新。拖动进度条定位游标，视窗围绕游标移动并在边界处限制；中间五组与右侧所选成分同步，末尾停止并保留最后一屏，再播放从头开始。绘图区游标时间使用源文件相对时间，播放位置显示分析区间内经过时间。

统一或各组适配的纵向标尺按完整分析区间确定，保持播放时稳定；峰峰值仍按当前通道、当前可见窗口计算。右侧“整段功率谱密度”使用整段分析的频谱，播放不会改变它。查看通道、每屏显示、幅度及成分切换时暂停，标签编辑、结果更换、导出和页面隐藏也会暂停；播放不触发重新拟合或改变科学数据与确认。

## 已接入输入及条件

| 输入 | 专用读取实现 | 条件与边界 |
| --- | --- | --- |
| 传统 RHD / RHS | Neo 0.14.5 RawIO 的 memmap 整数区间及通道读取 | 仅 header-attached；逐块验证时间戳连续与 32 位回绕；检查放大器单位和过量 ADC 轨值；拒绝 `info.rhd/info.rhs` 多文件模式 |
| HDF5 | h5py 指定通道和样本片段 | 显式 `eeg[C,N]`、正 fs、ch_names、物理单位；拒绝外链/虚拟数据及未支持的显式不规则时间轴 |
| EDF / 连续 EDF+ | pyedflib 逐通道 start/n 读取与物理校准 | 同采样率与样本数、明确单位；拒绝 EDF+D、BDF 伪装及不支持的布局；连续性以 EDF 连续文件约定为界，不冒称逐样本硬件时间戳验证 |
| CSV | 流式扫描和有界片段分配 | 首列 time_s，从 0 开始、有限且均匀；列尾声明 `[uV]` / `[mV]` / `[V]`，或一次人工确认源单位并记录到清单；不猜未知单位 |

输入数组按 double 的实际字节数在读前限制为 256 MiB；这不是进程峰值内存保证。完整来源 SHA-256 和 CSV 时间轴验证需要顺序扫描原文件，耗时随源大小变化；本轮未宣称大型文件性能门禁。

## 数值与架构

自有算法从 Pro 的纯数值实现迁移，没有引入 RHX 原生文件解析、设备控制或商业授权代码。边车负责全部科研格式 I/O，原生 `bf_dsp` 负责重采样、可选陷波、约 1 Hz 高通拟合副本、白化、FastICA、参考评分及重建。重建应用变换到未做该高通的输出副本，种子 42、最多 600 迭代、容差 `1e-6`。

专用控制器使用独立进程/快照、后台任务代次和协作取消；过期回调不得替换新记录。人工标签只更新缓存贡献。析构会取消并等待在途任务退出，避免对象销毁后的后台回调；正常取消不阻塞 UI。导出通过控制文件在组边界和每 256 行协作取消，等待边车清理暂存；原子发布临界区短暂不可取消或替换输入。

既有 IPC envelope / `float32-le` 浏览帧和协议版本 1 保持兼容，hello 增量声明 `source-f64-v1` / `bundle-f64-v1`，专用方法显式使用 `float64-le`。不具备能力的旧边车不能静默承接新分析。完整方法、错误与样本契约见[基础契约](../../contracts.md)，数值代码来源与逐值对照命令见[数值证据](offline-eeg-numerical-provenance.md)。

## 导出与恢复

输出到全新的结果文件夹，包含：

- `original_uV.csv`：抗混叠后、陷波前的观测副本。
- `analysis_uV.csv`：实际重建输入。
- `eeg_uV.csv` / `eog_uV.csv` / `emg_uV.csv` / `unresolved_uV.csv` / `residual_uV.csv`。
- `analysis.json`：`boundfree.community.offline-eeg.v1`，记录源文件 SHA-256、样本索引、通道用途、软件版本、矩阵、均值、收敛、评分、人工标签、确认和文件校验值。

CSV 第一列使用源文件相对时间，数字采用 17 位可回读精度。先验证 `analysis = mean + eeg + eog + emg + unresolved + residual`，再写隐藏暂存目录、回读每个 double、检查时间/形状/清单/重建误差，最后以不覆盖语义原子发布。源文件在读取与发布前检查是否变化；源记录和已有结果不被覆盖。失败保留内存结果与标签，可更换目录重试。

正常取消会清理暂存。强杀、断电等进程无法执行清理的情形可能留下 `.boundfree-analysis-*` 隐藏目录；它不属于正式结果目录，不能当作已发布分析。当前版本不提供跨崩溃自动恢复。

# EEG 界面与交互分阶段修复计划

## 范围与基准

以 `../archive/boundfree-eeg-upper-computer/boundfree_eeg/ui/` 为旧版参考（路径相对仓库根；该归档仅只读）。保留 C++/Qt6 主程序、Python 编解码边车与现有数值计算契约。用户反馈：功能栏难找难点、播放整窗跳动、频谱无结果、功能框移动漂浮、进度条拖动卡顿且无目标时刻、属性遮挡图像。

用户要求分阶段、小步提交。各阶段必须有独立验证和版本同步，不以一次全量重构交付。主代理负责集成、版本、提交；子代理分别调查/实施分析与回放，另设布局调查。所有提交遵守 `development-guide.md`，不发布安装包或直接推送远端。

## 已确认代码证据

- `native/src/ui/analysis_widgets.cpp`：SpectrumWidget 创建 QPainterPath 并设置画笔后遗漏 drawPath；PSD/FFT/相干共用该控件。
- `native/src/ui/eeg_playback_panel.cpp`：原实现仅在 sliderReleased 发 seek，没有 sliderMoved 时间预览。
- `native/src/ui/main_window.cpp`：advancePlayback 到当前窗口末尾前才请求下一窗；不得简单改为每帧请求。
- `native/src/controller/file_open_controller.cpp`：窗口请求重复创建工作线程/边车并打开文件；连续播放优化需要先解决会话与数据缓存。
- 阶段 3 已把单行 Browser 工具栏拆为顶部信号设置和底部播放区域，以 QSplitter 固定区域并禁用面板浮动。

## 验证边界

自动化离屏测试仅证明计算、绘制和交互状态契约，不替代 Windows 桌面流畅度或 DPI 验收。使用生成数据与公开测试夹具；不读取私钥或授权签发区。旧归档有本地改动，不回滚、不迁入。每阶段报告写入 `docs/reports/` 并更新索引；版本通过 `scripts/common/version_sync.py` 同步。

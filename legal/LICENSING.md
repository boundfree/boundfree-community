# Community 开源许可与付费扩展边界

本仓库采用“免费开源核心 + 独立商业扩展”。本文件说明许可范围和开发约定，不修改 Apache-2.0 或任何第三方许可证的条款。

## 免费开源核心

除文件自身、所在目录或第三方声明另有明确许可外，本仓库内 BoundFree 自有的源代码、脚本、配置、测试、文档和资源采用 **Apache License 2.0**（SPDX：`Apache-2.0`）。包括：

- `native/` 中的自有 C++/Qt 主程序、DSP、ICA、控制器、界面和授权客户端代码；
- `sidecar/` 中的自有 Python 编解码与 IPC 实现；
- `scripts/`、`tests/`、`contracts/`、`installer/`、`.github/` 和 `.agents/` 中的自有实现；
- 自有使用文档、翻译，以及有明确自有来源的合成教学与测试资源。

当前 ICA 拟合、人工成分标记、分组重建和结果导出均属于开源核心。本次不将已有核心实现转成付费专有代码。

许可允许个人、科研和商业使用，以及按许可条件修改、再分发和开发商业扩展。不得向开源核心附加“禁止商用”“不得修改授权检查”或“必须向 BoundFree 付费才能再分发”等限制。第三方也可在遵守许可条件时提供自己的收费发行版。

根目录 `LICENSE` 是 Apache-2.0 完整正文，`NOTICE` 保留项目归属说明；安装包随附的 `legal/LICENSE.txt`、`legal/NOTICE.txt` 分别与两者保持一致。再分发时遵守许可证关于许可副本、归属和修改声明等要求。

Apache-2.0 第 6 节不授予 BoundFree 名称、商标或标识的商标使用权，仅保留该节允许的合理来源描述和 NOTICE 复现用途；修改版不得暗示获得官方背书。这不缩减开源代码的使用、修改和再分发权利。

## 第三方组件与外部数据

本次不重新许可第三方作品。`native/third_party/`、`legal/licenses/`、`installer/installer_languages/` 中的第三方内容，以及依赖、外部记录和数据集，继续适用各自原始许可、归属与获取条件。具体以文件内声明、来源记录及 [第三方声明](THIRD_PARTY_NOTICES.md)、[第三方许可](THIRD_PARTY_LICENSES.md) 为准。

测试夹具或教学资源只有在来源明确为 BoundFree 自有合成时才纳入上述 Apache-2.0 范围；不得因将外部文件复制进仓库就推定取得重新许可权。用户导入的科研数据及其分析输出不因使用本软件而被本项目重新许可。

Pro、商业授权服务端以及工作空间中其他仓库不属于本仓库的开源许可范围。历史 Git 记录和旧报告只供追溯，旧文档中的主程序专有许可表述不作为本树的当前许可依据；不覆盖旧 tag 或已经分发的安装包。

## 付费扩展

未来付费扩展使用**独立私有仓库**管理源码、商业许可、版本、构建和安装产物。本 Community 仓库不创建混合许可的专有源码目录，不提交扩展源码、私有实现或商业密钥。

- 扩展通过公开、版本化接口与核心集成；接口及 Community 侧的通用适配代码继续开源。具体插件或进程接口尚未实现，不能当作现有能力承诺。
- 核心能够独立构建、测试和运行；不得强制依赖私有仓库、付费扩展或其构建凭据。
- 扩展的商业许可仅覆盖相应权利人有权许可的扩展部分；引用核心或第三方组件时仍须遵守原许可并随包保留声明。
- 批量自动化、流程模板、辅助分析和报告可作为后续付费候选；逐项确认范围、实现及验收后再承诺，不在本次定义价格或现成商品。
- 基础分析、必要的质量提示、科学数据精度和基本结果导出保留在免费核心。

## 授权实现与后续验收

**本次仅完成许可与源码管理边界；现有官方安装包仍有整机激活门禁。** 源码默认开发构建不启用 `BF_REQUIRE_LICENSE`，但这不等于官方免费包已完成迁移。旧许可证和授权服务的兼容代码本次保留。

在以“免费核心 + 付费扩展”正式交付前，须另行实现并验证：免费核心无需付费授权即可使用；授权只控制相应扩展；缺失或到期的扩展授权不阻断核心和已有基础结果访问。若选择买断加更新服务，还需分开表达已购版本使用权与更新期限。不能把本文件或当前整机许可证当作已经实现的功能权益系统。

提交到开源核心的贡献按 Apache-2.0 第 5 节处理，除非另有明确协议。贡献者须有权提交相应内容，并保留第三方声明；不默认转移版权，也不默认授予将他人贡献改为专有许可的权利。

新增代码先确定归属：核心及公开集成放本仓库，商业扩展放对应私有仓库。新建自有源码建议使用 `SPDX-License-Identifier: Apache-2.0`；不批量覆盖第三方文件头。交付按源码仓库的 `docs/contribution-sop.md` 和 `docs/release-sop.md` 检查许可文件与打包副本，第三方实际分发依赖仍需单独核验。

# 统一设备与录制文件的信号工作台实施计划

## 任务与实施位置

用户要求设备实时数据与已录制文件接入同一套处理、波形和分析工具，原始录制保持独立，禁止按数据来源整组禁用功能，完成后导出新的 Windows 内部测试安装包。本文按用户指定写入本仓库 archive/plans；实际代码继续位于独立工作树 `.worktrees/community-ica` 的 `feature/bfsp-acquisition`（3911fc58 加既有未提交改动），保留已有工作。不自动提交代码、推送、创建 PR/tag/Release 或实际安装；主目录清理与文档按用户要求保留为本地提交。源码产品版本保持 0.2.2-beta.1，构建副本采用新的唯一 dev 标识。

## 已确认的问题

1. MainWindow 共用 WaveformWidget，但设备模式隐藏预处理/分析并提前跳过处理和分析请求。
2. Capture 回放虽已读出数据、单位与显式样本时间，仍按来源禁用处理/分析/导出；现有 smoke 甚至将禁用作为验收条件。
3. 设备界面只取得最多 16 通道、约 1600 点/通道的极值绘图包络，不能将其用作均匀采样的 FFT/滤波输入。
4. ProcessingPipeline 已有 realtime/offline 两种执行方式，实时方式尚未贯通产品链路；AnalysisRequest 尚未携带单位、时钟、缺口与来源上下文。
5. 文件分析与导出假设 µV、规则索引；ICA 输入是另一套路径和电压单位读取器。简单删除界面 guard 会误标单位、跨缺口滤波或选错分析区间。

## 架构约束

- 两种入口：设备适配器/通用协议解码；录制文件读取器。两者向公共信号视窗提供完整样本、通道身份、采样率、单位/标定、时间轴、连续片段、来源、会话/代次及处理上下文。
- 原始存储保留类型与元数据；处理/分析使用数值投影，不写回原始样本。文件 I/O 仍由 Python 边车执行。
- 原始录制直接订阅既有 SignalHub，与显示、处理、暂停查看、分析及其背压独立。
- 绘图抽稀仅用于显示。分析必须读取原始或处理后的完整有效样本，不能将 min/max 包络当作规则波形。
- 工具按具体数据条件检查：可用连续长度、Nyquist、通道单位兼容、共同时间轴等。count 可以滤波和做频谱，输出相应 count、count²/Hz；不得冒充 µV。
- 同一个工作台、处理参数及通道选择。来源只改变连接/播放/录制控制；分析、预处理不因来源整组隐藏。
- 实时与离线共用算法和参数，但显式区分因果连续处理与离线零相位区间处理。同一模式、同一数据、同一参数下比较结果，不把两种相位语义宣称完全相同。
- 缺口分段、滤波状态重置和任务代次隔离；不同采样率/未同步时钟不得直接拼接做跨流相干分析。实时 ICA 使用选定缓存段的稳定快照，不阻塞接收或自动反复拟合。

## 实施步骤

1. 建立公共信号视窗/连续片段、单位与来源上下文；统一切窗、处理、分析输入。为设备暴露后台读取的完整原始窗口，保留绘图包络作为可选显示优化。
2. 接入公共处理流程：重参考、陷波、带通；明确混合单位限制；原始/处理后选择同时驱动绘图与分析。处理缺口时分段，离线使用上下文再裁剪，实时处理维护或明确窗口执行模式。
3. 统一 FFT/PSD/STFT/频段趋势/相干性入口、结果单位和时间标注，增加有效片段与数据不足提示；在同一工作台显示工具。
4. 将 Capture 和设备快照接入选区导出/离线分离的公共输入桥。保留原始数据单位、来源与处理说明；目标格式不支持时只限制该操作并显示原因。
5. 改写旧“整类禁用”为“跨来源一致性”验收，验证暂停查看/切换源/分析不影响采集与原始录制。
6. 同步契约、架构和操作文档；构建 Linux/Windows、重冻边车，运行打包态回归、检查四语/主题/窄窗，核对源码快照、版本与 SHA256 后导出新安装包。

## 验收

- 同一批样本通过模拟器/设备适配器与录制文件进入，在相同执行模式及参数下，原始数值、处理结果与频谱在规定容差内一致。
- 实际旧 Capture 可打开、滤波、查看频谱、拖动播放；count 单位正确，不修改源文件摘要。
- 实时采集时可使用同一套处理和分析；查看暂停、分析重算、切换工具不暂停接收或原始录制；不使用抽稀包络作分析。
- 缺口、短窗口、混合单位、不同采样率/时钟、停止重启、断开和迟到回调有明确行为，不能默默补零或产生伪连续结果。
- 原始录制在改变处理设置前后保留相同原始样本；完整录制仍可回读并校验。
- 普通 CSV/EDF/HDF5 浏览、播放、既有处理导出及独立 ICA 工作流通过回归；修改原有测试中的错误禁用预期。
- 冻结边车和安装包内程序验证，不以开发态 Python 回退替代。保留授权、沿用 RT-BCI 测试版独立安装 ID、未签名，真实设备/干净机/高 DPI 验收单独报告。

## 验收边界

共享浏览、处理、分析及选区分离快照仍为 float32 数值投影，不能宣称恢复原始 float64 精度；原始 typed 文件独立保存，专用分离直接打开原文件继续使用 float64。窗口零相位与连续因果的相位/边界/初始状态不同，只在同一模式和初始状态下比较来源一致性。

实时完整窗口最长10秒且受32MiB预算限制，过大需缩短窗口。分析选最长有效连续片段并显示真实区间，不跨缺口补零。多流各自选择，不凭名义速率猜同步；一般硬件事件叠加、周期同步和长稳/高通道吞吐仍待验收。界面人工标注保存在派生导出，不能据此宣称硬件触发已贯通。

旧用户记录未接脑电帽且为 partial，本轮验证其原始样本可读和源文件不变，不证明生理信号质量、ADC实际速率或无丢样。另一台测试电脑的安装、高DPI、真实RT-BCI和电极体验仍待用户验收。产品版本仍为0.2.2-beta.1，本包为独立开发候选。
